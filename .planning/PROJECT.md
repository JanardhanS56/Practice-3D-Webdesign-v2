# Project: VÉRITÉ BOTANIQUE (High-End Herbal Hair Oil Experience)

## Vision
A hyper-detailed, immersive 3D product webpage for an artisanal herbal hair oil brand. Built with a bespoke Three.js 3D viewport, 60|30|10 color hierarchy (60% Deep Obsidian Black, 30% Smoked Botanical Slate / Herbal Amber, 10% Vivid Bio-Lime / Neon Green), interactive bottle customization, botanical extraction journey, diagnostic scalp quiz, and comprehensive compliance/privacy architecture.

## Tech Stack
- Frontend: React 18, Vite, Tailwind CSS, Lucide React, Canvas / Three.js PBR rendering
- Animations: GSAP / Ticker sync & CSS 3D transforms
- Backend: Express.js / Node.js API (orders, diagnostic assessment, ingredient certificates, newsletter)
- Audio/Sensory: Web Audio API ambient soundscape synthesis (rainforest drizzle / botanical extraction hum)

## Brand Aesthetics & Palette (60 | 30 | 10 Rule)
- 60% Black / Obsidian (`#080B09`, `#0D110E`, `#050705`)
- 30% Botanical Secondary (`#142017`, `#1A281E`, Smoked Sage `#8DAA96`, Warm Amber `#D9943B`)
- 10% Vivid Lime / Neon Green Accent (`#38EF7D`, `#10E569`, `#4ADE80`)
- Display Typography: Cormorant Garamond & Syne
- Body Typography: Plus Jakarta Sans / Manrope

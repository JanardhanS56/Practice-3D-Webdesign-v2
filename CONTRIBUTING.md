# Contributing

Thanks for contributing to Practice-3D-Webdesign-v2.

## Development setup

1. Install Node.js 18 or newer.
2. Install dependencies with `npm ci`.
3. Start the frontend with `npm run dev`.
4. If working on API routes, start the API in another terminal with `npm run server`.

## Before opening a pull request

- Run `npm run build` and resolve any build errors.
- Test the affected interactions in the browser, including a narrow/mobile viewport when relevant.
- Keep changes focused and follow the existing React, JavaScript, and Tailwind patterns.
- Do not commit generated output, `node_modules`, credentials, or local environment files.

## Pull requests

- Use a descriptive branch name, such as `fix/mobile-navigation` or `feat/product-dossier`.
- Explain what changed and why in the pull request description.
- Include screenshots or a short recording for visible UI changes.
- Note any manual checks that could not be completed.

Use clear, descriptive commit messages. Existing history uses Conventional Commit-style prefixes such as `feat`, `fix`, and `chore`.
